# Shorts shared scene blocks

One template folder per format. Mirrors the folder layout under `Contents/Shorts/`:

```
Pipeline/shorts/
├── one_question/
├── cosmic_profile/
├── think_like_a_physicist/
├── concept_burst/
├── science_brief/
└── teaser/
```

Each template folder holds the reusable Manim code for that format (default hook, structure, transitions). Produced videos still live under `Contents/Shorts/<format>/<date-slug>/`.
