# Long-form shared scene blocks

Reusable Manim scenes used across multiple long-form episodes. Episode-specific scenes live under `Contents/Long-form/episodes/<date-slug>/scene_*.py`.

Typical contents:
- intro / outro wrappers around `common.branding`
- standard diagrams reused often (HR diagram, light cone, coordinate axes)
- transition helpers between beats

Add a new shared block here only when it's used in three or more episodes. Episode-specific scenes stay in the episode folder.
